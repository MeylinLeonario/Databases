# Tracker de videojuegos — Registra videojuegos, plataforma, horas jugadas y estado. Busca los más jugados y calcula horas totales.

Algunas funciones básicas que se pueden utilizar con `SELECT`:

| Comando    | ¿Qué hace?                    | Ejemplo                    |
| ---------- | ----------------------------- | -------------------------- |
| `SUM()`    | Suma los valores              | `SELECT SUM(horasJugadas)` |
| `AVG()`    | Calcula el promedio           | `SELECT AVG(horasJugadas)` |
| `COUNT()`  | Cuenta registros              | `SELECT COUNT(*)`          |
| `MAX()`    | Obtiene el valor máximo       | `SELECT MAX(horasJugadas)` |
| `MIN()`    | Obtiene el valor mínimo       | `SELECT MIN(horasJugadas)` |
| `DISTINCT` | Devuelve valores sin repetir  | `SELECT DISTINCT(genero)`  |
| `*`        | Selecciona todas las columnas | `SELECT *`                 |
